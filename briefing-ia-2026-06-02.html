IA — modèles, produits, communications

Microsoft Project Polaris : Copilot coupe le cordon OpenAI

Annoncé à Build 2026 le 2 juin. Polaris est un modèle MoE spécialisé par langage/framework, avec reasoning chain-of-thought et tree-of-thought à l'inférence, entraîné sur Maia 200 (puce maison Azure). Microsoft revendique des gains sur HumanEval et MBPP vs GPT-4 Turbo, particulièrement sur Rust et Haskell. Remplacement par défaut sur tous les abonnements GitHub Copilot à partir d'août, fallback GPT-4 optionnel jusqu'en novembre.

→ techtimes.com — 2 juin · aiweekly.co — 2 juin

→ Pour le lecteur : signal large que les plateformes (Microsoft ici, peut-être Strava côté sport) préfèrent désormais leur stack maison plutôt qu'une dépendance à un modèle externe. À mesure que le coût d'inférence chute (~10x/an), construire son propre layer de reasoning sur des données capteurs devient économiquement défendable — c'est exactement la fenêtre dans laquelle ton produit doit accélérer.
OpenAI frontier models et Codex disponibles sur AWS Bedrock

GPT-5.5, GPT-5.4 et Codex désormais accessibles dans AWS Bedrock avec gouvernance et sécurité AWS-native. Annoncé conjointement par OpenAI et Amazon le 2 juin, en prolongement du deal stratégique de 38 Md$ d'avril. "Codex on Bedrock" cible explicitement les workflows enterprise de software engineering. Mention d'une future intégration "Daybreak" (vision OpenAI sur la transformation du dev).

→ openai.com — 2 juin · aboutamazon.com — 2 juin

Build 2026 : Windows Agent Framework 1.0 open source, Azure Agent Mesh, Foundry Local GA

Microsoft pousse Windows comme plateforme d'agents : framework 1.0 MIT-licensed, Azure Agent Mesh pour exécution fédérée multi-cloud/multi-device, Foundry Local en GA (modèles IA on-device sur Windows/macOS/Linux), et Agent Mode passé en default dans Office 365 Copilot. Le pivot de fond : faire de l'OS un substrat d'orchestration d'agents plutôt qu'un simple host d'apps.

→ buildfastwithai.com — 2 juin · chatforest.com — 2 juin

→ Pour le lecteur : Foundry Local GA = brique technique potentiellement réutilisable. Possibilité de faire tourner un layer IA on-device pour ton coach adaptatif (latence, vie privée des données capteurs, coûts) sans dépendre d'un appel API distant à chaque interaction. À évaluer concrètement contre tes contraintes mobile/wear.

Applications d'entraînement sportif

Strava ouvre l'accès complet à son historique via Claude (MCP connector)

Lancement officiel le 1 juin pour tous les abonnés Strava. Le connecteur expose en read-only via OAuth les streams par seconde (HR, pace), GPS, puissance vélo, et métadonnées clubs/événements. L'utilisateur pose des questions en langage naturel à Claude qui répond depuis la donnée live Strava — pas un export figé. Strava se positionne comme la première grande plateforme connected fitness à expédier une intégration assistant IA native. À distinguer d'Athlete Intelligence (résumé post-activité, déjà déployé) : le MCP est conversationnel sur l'historique long.

→ press.strava.com — 1 juin · support.strava.com — 1 juin · the5krunner.com — 1 juin

→ Pour le lecteur : menace directe sur deux axes — (1) un athlète Strava peut désormais obtenir une analyse adaptive personnelle "à coût d'abonnement déjà payé" via Claude, ce qui érode le willingness-to-pay pour un coach IA standalone ; (2) ton positionnement "le plan s'adapte aux contraintes" reste défendable si tu agis (planification multi-horizon, contraintes vie, intégration météo/équipement) là où Claude+Strava sert surtout l'analyse rétrospective. Le5krunner note d'ailleurs que la vraie barrière déjà tombée, c'était Apple/Google Health en janvier — Strava ne fait que formaliser un canal contrôlé. Conséquence : la valeur ne vient plus de la possession de la donnée mais de la qualité du modèle d'arbitrage en aval.
Strava + Runna : challenge Global Running Day 5K le 3 juin

Strava et Runna (acquis 2025) lancent un challenge conjoint pour battre le record du plus grand nombre de 5K en une journée, le 3 juin (Global Running Day). Inclusion (course OU marche) plutôt que compétition. Moins une nouveauté produit qu'un signal d'intégration marketing post-acquisition.
